# guess_the_code
# codebreaker Game

This is a simple guessing secret code game implemented in JavaScript. The goal of the game is to guess a randomly generated secret code within a limited number of moves.
# Features

    Randomly generates a 4-digit secret code.
    Provides feedback on each guess:
        Blue dots: Correct digits in the correct position.
        White dots: Correct digits but in the wrong position.
    Displays move history for user reference.
    Ends the game when the code is guessed or moves run out.

# How to Play

    The game generates a secret 4-digit code when it starts.
    Enter your guess in the input box and submit.
    Feedback will be displayed:
        Number of digits in the correct position.
        Number of digits correct but in the wrong position.
    Continue guessing until:
        You guess the correct code, or
        You run out of moves.
    After the game ends, the secret code will be revealed if you lose.

# Technologies Used

    HTML: For the game structure.
    CSS: For styling and visual feedback (e.g., dots).
    JavaScript: For game logic and interactivity.
